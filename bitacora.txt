
### **Resumen de Bitácora: Proyecto Web "Rueda Libre"**

#### **1. Configuración y Estructura Base**

* **Entorno:** Local (`[http://127.0.0.1:5500/index.html](http://127.0.0.1:5500/index.html)`) / Producción (`[https://sara042.github.io/rueda-libre/](https://sara042.github.io/rueda-libre/)`). Códigos HTTP clave: `200` (OK) y `304` (Sin cambios), con control de errores `404`.
* **Roles de Desarrollo:** HTML (estructura), CSS (presentación visual) y JavaScript (comportamiento interactivo).
* **Semántica HTML:** Uso estricto de regiones (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`) y jerarquía lógica de encabezados (`<h1>` único por página, `<h2>`, `<h3>`).

#### **2. Navegación y Rutas**

* **Páginas del sitio:** `index.html`, `paginas/tarifas.html`, `paginas/reservas.html`.
* **Rutas relativas:** Correctamente enlazadas desde la raíz (`paginas/...`) y desde subcarpetas (`../index.html`).

#### **3. Formulario y Validación**

* **Controles:** `type="email"` (validación nativa de formato), `<select>` (selección única de vehículos), `<textarea>` (comentarios multilínea).
* **Pruebas de Validación (8 Min):** Todas superadas exitosamente mediante bloqueos nativos ante errores de longitud mínima (`minlength`), patrones numéricos/celular, campos obligatorios, términos y condiciones y correos sin `@`.

#### **4. Accesibilidad (A11Y)**

* Textos alternativos (`alt`) auditados (informativos y decorativos vacíos).
* Enlaces descriptivos corregidos (eliminación de textos genéricos como "haz clic aquí").
* Idioma establecido (`lang="es"`) y navegación completa por teclado probada.

#### **5. Diseño y Color (UI/UX)**

* **Fondo general:** Crema (`#FDFBF7`).
* **Textos:** Azul Noche (`#1E293B`) para cuerpo y Gris Asfalto (`#475569`) para subtítulos.
* **Destacados:** Verde Ruta (`#0D9488`) para botones y enlaces; Naranja Pedal exclusivamente para elementos gráficos/decorativos. Contraste validado para accesibilidad.

#### **6. CSS y Herencia**

* **Herencia:** Propiedades como tipografía (`font-family`) se heredan automáticamente; los márgenes (`margin`) no.
* **Mini Reto (Especificidad CSS):** Se solucionó el conflicto de la clase `.activo` combinándola con el selector de ID del menú (`#menu a.activo`) para darle mayor peso de cascada frente a las reglas generales.

---
### **7. MEDICIÓN DE CAJA ** 
Sin utilizar el box-sizing border:box la caja tiende a tener desbordamientos (el padding y el borde se suman por fuera) por el contenido que se le va añadiendo.
Al utilizar el box-sizing border:box se aplica una regla global, el ancho total de la caja en este caso es de 300px, con esta regla el navegador se encarga de organizar todo el relleno y lo sbordes hacia adentro, sin alterar el tamañano previamente elegido
